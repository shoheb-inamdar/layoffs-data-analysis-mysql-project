# Layoffs Data Analysis using MySQL

## Project Overview

This project focuses on analyzing a cleaned layoffs dataset using MySQL.
The objective was to extract meaningful business insights and identify trends
in company layoffs.

## Tools Used

- MySQL
- SQL

## Dataset

The dataset contains information about company layoffs including:

- Company
- Location
- Industry
- Total layoffs
- Percentage layoffs
- Date
- Company stage
- Country
- Funds raised

## Analysis Performed

- Identified companies with highest layoffs
- Analyzed layoffs by industry
- Studied country-wise layoffs
- Analyzed yearly layoff trends
- Compared layoffs based on company stage

## SQL Concepts Used

- Aggregate Functions
- GROUP BY
- ORDER BY
- CTE
- Window Functions
- Date Functions
- Ranking

## Business Insights

- Found companies with maximum layoffs
- Identified industries highly affected
- Compared layoffs across different countries
- Analyzed changes in layoffs over time

## Outcome

Created an analytical report using SQL to understand layoff patterns
and generate data-driven insights.
